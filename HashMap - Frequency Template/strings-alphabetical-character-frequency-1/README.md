## Problem Description

Given a string S, count the frequency of each character and print the result in the format 'char+frequency'. The output must be sorted alphabetically by the character.

### Input Format
A single string S.


### Output Format
Characters followed by their counts in alphabetical order, each on a new line.


### Constraints
1 <= S.length <= 10^5
S contains lowercase English letters.
