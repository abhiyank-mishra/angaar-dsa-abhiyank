# Get the Maximum element in the mountain Array

**Difficulty:** `Medium`  

**Sheet:** Binary Search  

**Language:** java  

**Platform:** [The Angaar Batch](https://theangaarbatch.in/courses/flare-10--dsa-with-java/solve/get-the-maximum-element-in-the-mountain-array)  

## Problem Description

You are given an array first having element  increasingly sorted then after a peak index it is decreasingly sorted.
Ex:- 1,2,3,4,5,3,2,1
             i  i   i    i    p d d d
(i for inc
p for peak
d for dec)

you have to find out the index of biggest element or simply the top of the mountain array.

### Input Format
first line N
second line N space separated integers which are elements of mountain array.


### Output Format
single integer which is the peak element index.


### Constraints
3<=N<=10^9
