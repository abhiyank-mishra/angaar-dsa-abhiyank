## Problem Description

Given an array of integers and an integer K, return the number of non-empty subarrays that have a sum divisible by K.

### Input Format
An integer N, followed by N space-separated integers, and finally the divisor K.


### Output Format
The total count of subarrays whose sum is a multiple of K.


### Constraints
1 <= N <= 10^5
2 <= K <= 10^4
-10^4 <= nums[i] <= 10^4
