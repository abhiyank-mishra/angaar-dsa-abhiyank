# Sliding Window: Minimum Window Substring

**Difficulty:** `Hard`  

**Sheet:** Sliding Window | Variable Size  

**Language:** java

## Problem Description

Given two strings s and t of lengths m and n respectively, return the minimum window substring of s such that every character in t (including duplicates) is included in the window. If there is no such substring, return the empty string "".

### Input Format
The platform provides T test cases.
For each testcase, a single line contains two space-separated strings: s and t.


### Output Format
For each testcase, print the minimum window substring on a new line. If no such substring exists, print an empty line.


### Constraints
1 <= s.length, t.length <= 10^5
s and t consist of uppercase and lowercase English letters
