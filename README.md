# 🔥 Angaar Toolkit Pro v2.3 (Super Extension for The Angaar Batch)

The ultimate all-in-one companion tool for students and admins on **The Angaar Batch** (theangaarbatch.in). Also includes auto-synced solutions and code submissions.

---

## 🌟 Included Features

### 1. 🛡️ Admin Contest Shield (Zero-Flag Enforcer)
- Complete anti-cheat proctoring bypass for Admin/Pro users during live contests.
- Neutralizes tab-switch detection, window blur, and fullscreen enforcement.
- Suppresses flag warnings and blocks telemetry reports to ensure 0 flags counted.

### 2. 🏆 Full 600+ Member Leaderboard
- Ek click me sabhi 600+ students ki real-time ranks, names, total scores aur solved questions dekhein.
- Zero pagination: 7-7 karke 60 baar Next dabane ka jhanjhat khatam!
- Live Instant Search (Name, Rank, ya Student ID se).
- One-Click Excel / CSV Export.

### 3. 📊 Top 10 Peer Gap Analysis
- Rank #1 aur Top 10 students ka topic-by-topic solved analysis.
- Dekhein Top 10 rankers ne kaunse topics (Binary Search, HashMap, 2 Pointer, Monotonic Stack, etc.) me kitne questions solve kiye hain taaki aap unhi high-yield topics par focus kar sakein.

### 4. 🐙 AngaarHub (GitHub Auto-Sync)
- Jaise LeetCode ke liye *LeetHub* hota hai, waise hi Angaar ke liye auto-sync!
- Jab bhi aap koi problem submit karenge aur testcases pass honge (**Accepted**), extension automatically aapke solution code ko aapke personal GitHub repository me push kar dega!
- Instant portfolio building on GitHub.

### 5. 📋 Notion & Markdown Sheet Checklist
- Angaar DSA sheets ko ek click me Notion / Markdown checklist me export karein taaki aap offline progress track kar sakein.

## 🛠️ How to Install in Chrome / Brave / Edge (30 Seconds)

1. Browser me URL bar me open karein:
   `chrome://extensions`
2. Top-right corner me **Developer mode** switch ko **ON** karein.
3. Top-left corner me **Load unpacked** button par click karein.
4. Is folder ko select karein:
   `C:\Users\hello\.gemini\antigravity\scratch\angaar-leaderboard-extension`
5. Extension successfully install ho jayegi!

---

## 🐙 How to Enable GitHub Auto-Sync

1. Webpage par bottom-right me **"Pro"** button click karein.
2. **"🐙 GitHub Auto-Sync"** tab me jayein.
3. Apna GitHub Token (with 'repo' scope) aur Repository name (e.g. `your-username/angaar-dsa-solutions`) daal kar **"Save & Enable Auto-Sync"** click karein.
4. Ab jab bhi aap koi code submit karenge, toast notification aayega aur code directly GitHub par commit ho jayega!
