## Problem Description

Given an array and an integer `k`, return true if there are two distinct indices `i` and `j` such that `nums[i] == nums[j]` and `abs(i - j) <= k`.

### Input Format
An integer N, followed by N integers and an integer k.


### Output Format
true or false.


### Constraints
1 <= N <= 10^5
0 <= k <= 10^5
-10^9 <= nums[i] <= 10^9
