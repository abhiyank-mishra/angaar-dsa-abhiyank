## Problem Description

Given an array of integers `nums` and an integer `target`, return the 0-based indices of the two numbers such that they add up to `target`. You may assume that each input would have exactly one solution.

### Input Format
An integer N, followed by N space-separated integers, and finally the target sum.


### Output Format
Two space-separated indices.


### Constraints
2 <= N <= 10^5
-10^9 <= nums[i] <= 10^9
-10^9 <= target <= 10^9
